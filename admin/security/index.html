Security Settings

Security is enforced via JWT sessions (HttpOnly, Secure, SameSite=Lax cookies) and server-side password hashing with a pepper secret. Configure JWT_SECRET and PASSWORD_PEPPER via wrangler pages secret put. Two-factor/OTP login is available at /api/auth/request-otp and /api/auth/verify-otp.

Two-Factor Authentication (2FA)

Backed by the two_factor_auth table. Toggle enforcement for admin accounts here.

Rate Limiting

Login and OTP endpoints are tracked in the rate_limit_events table for abuse detection. Configure thresholds by extending the API worker.
