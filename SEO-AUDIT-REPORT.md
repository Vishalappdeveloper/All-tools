# SEO / AEO / GEO Audit Report — allfreecalculators.in

> Scope note: this audit was run entirely against the uploaded project ZIP (static files + Worker source). There is no live crawler access to the production domain, no Cloudflare account, and no Google Search Console API access in this environment, so live HTTP status/canonical crawling (Phase 21/23 "automated crawler") could not be executed against the real domain. Findings below are from direct source inspection, which is authoritative for canonical/robots/sitemap *logic*, but cannot confirm live server headers or Google's current index state.

## Deferred / requires information this environment does not have
1. **505 "Alternative canonical" + 25 "Duplicate canonical" exact URLs** — need the GSC CSV export (Search Console → Pages → export) to classify each URL individually per the Phase 6 decision tree. Guessing would risk exactly the "blind canonicalization" the master prompt forbids.
2. **Live "Your Dashboard class="page">" bug** — not present in this ZIP; need the current live HTML (view-source) to locate.
3. **Real D1 database ID / remote schema state** — `wrangler.toml` ships with a placeholder `database_id`; only the project owner running `wrangler d1 list` against their real Cloudflare account can confirm/apply the migration remotely (see `D1-MIGRATION.md`).
4. **Whether `sitemap-finance.xml` / `sitemap-health.xml` / `sitemap-currency.xml` still exist on the live server** — not present in this ZIP; if they exist live they should be removed as stale artifacts, not recreated.
5. **Live HTTP status/redirect crawling of the actual domain** — not performed (no permission/tooling to mass-crawl the live site in this task); redirect-map correctness (2,979 entries, 0 chains, all 301) was verified from source code logic instead.
